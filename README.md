# Atelier Integral Website

Atelier Integral の公式ウェブサイトを構成する、ポートフォリオ用途の公開ソースコードです。

日常の開発・更新は非公開リポジトリで行い、公開可能な変更だけをこのリポジトリへ反映します。このリポジトリを開発の正本として直接更新する運用は行いません。

## Development

```sh
npm ci
npm run dev
```

本番ビルドは `npm run build` で生成できます。

## Contributions

このリポジトリはソースコード・ポートフォリオとして公開しています。外部からの Pull Request は受け付けていません。
